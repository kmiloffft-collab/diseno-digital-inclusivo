RECURSO MULTIMEDIA EDUCATIVO

Diseño Digital Inclusivo

Guía práctica para crear contenidos digitales más accesibles, comprensibles e incluyentes, siguiendo principios de accesibilidad WCAG.

Bienvenido/a

La accesibilidad digital permite que más personas puedan percibir, comprender y utilizar los contenidos en internet, incluidas personas con discapacidad.

Explora los módulos, realiza las actividades y finaliza con la evaluación.

Objetivos de aprendizaje
  • Reconocer la importancia del contraste y el uso del color.
  • Describir imágenes mediante textos alternativos útiles.
  • Comprender la navegación mediante teclado.
  • Aplicar buenas prácticas básicas de accesibilidad.

1. Contraste y uso del color

El texto normal debe alcanzar una relación de contraste de al menos 4.5:1 y el texto grande 3:1 como referencia WCAG.

Ejemplo legible: texto oscuro sobre fondo claro.
Ejemplo difícil: texto gris sobre fondo gris.

No uses únicamente el color para comunicar información; acompáñalo con palabras o símbolos.

Actividad rápida

¿Cuál combinación facilita más la lectura?

2. Texto alternativo para imágenes

El texto alternativo comunica el propósito o la información importante de una imagen a quienes no pueden verla o utilizan lectores de pantalla.

Ejemplo: Estudiante usando un computador portátil en una biblioteca.

Un buen texto alternativo es breve y específico. Las imágenes decorativas pueden llevar texto alternativo vacío.

Actividad rápida

Para un gráfico que muestra el aumento de ventas, ¿qué opción es más útil?

3. Navegación con teclado

Una página accesible debe poder recorrerse sin mouse. La tecla Tab mueve el foco entre controles y Enter o Espacio activa muchos de ellos.

  • Usa un orden de navegación lógico.
  • Haz visible el indicador de foco.
  • Incluye enlaces para saltar al contenido principal.
  • No crees trampas de teclado.
Prueba a recorrer los botones usando Tab. Observa el borde amarillo que indica dónde está el foco.

4. Evaluación final

Selecciona una respuesta para cada pregunta y pulsa “Validar respuestas”.

1. ¿Cuál es el contraste mínimo recomendado para texto normal según WCAG?

2. ¿Para qué sirve el texto alternativo?

3. ¿Qué tecla permite avanzar entre elementos interactivos?

4. ¿Es correcto comunicar un error solamente con color rojo?

5. ¿Qué indica un foco visible al navegar con teclado?

Reflexión

La accesibilidad debe considerarse desde la planificación y el diseño. Buen contraste, textos alternativos y controles accesibles por teclado mejoran la experiencia de muchas personas.
